# 🧠 Quiz Game

This is a fun, interactive, and timed multiple-choice **Quiz Game** built using **HTML**, **CSS**, and **jQuery**. Players are tested on general knowledge questions and get instant feedback on their performance.

## 🎮 Features

- 10-question multiple-choice quiz  
- 10-second timer per question  
- Progress bar animation  
- Dynamic scoring  
- Win or lose message based on performance  
- Sound feedback (correct/wrong)
- Responsive layout with fun styling
